# Windows Resilience Suite

This directory is the publication workspace for a family of Windows projects reconstructed from the complete `lockdown`, `performance`, and `Keep X.com blocked` Codex task histories, plus related cleanup and backup tasks.

Each child directory is designed to become an independent GitHub repository. The projects share four rules:

1. Audit before changing the machine.
2. Require explicit confirmation for privileged or destructive work.
3. Preserve school, Microsoft, Xbox, gaming, finance, developer, accessibility, and official Qobuz workflows.
4. Never ship secrets, device-specific identifiers, personal inventories, live policy hashes, or instructions that weaken permanent hard gates.

## Projects

| Repository | Purpose |
|---|---|
| `ai-workspace-guardrails` | Enterprise project isolation, agent preflight authorization, NTFS boundaries, integrity evidence, and safe handoffs. |
| `windows-lockdown-guardian` | Layered Windows website/app restrictions, integrity manifests, verification, and self-repair. |
| `windows-protected-paths` | Manual file/folder selection with SYSTEM-managed read-only ACL enforcement and integrity monitoring. |
| `lean-windows-performance` | Conservative performance audit and optimization with vendor/service guardrails. |
| `windows-maintenance-orchestrator` | Hidden daily, weekly, startup, sign-in, post-update, and self-heal maintenance tasks. |
| `adaptive-gaming-power` | AC/battery power profiles, per-game GPU routing, inventory, and safe-windowed launch helpers. |
| `windows-cleanup-auditor` | Audit-first cleanup of orphaned game data, launcher caches, temp files, and crash dumps. |
| `windows-backup-integrity` | Versioned backups, SHA-256 manifests, verification, and safe restore staging. |
